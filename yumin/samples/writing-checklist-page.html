바뀐 점

    1. 쓸 때 따르는 규칙

    AI에게 문장을 쓰게 할 때 프롬프트에 넣는 것입니다. 하라는 형태로만 씁니다.

    2. 쓴 뒤 거르는 항목

    프롬프트에 넣지 않고, 쓴 글을 점검할 때만 씁니다. 자동 점검은 yumin/tools/sample-lint.py(아직 v1 기준)입니다.

    3. 사람이 판단하는 항목

    4. 좋은 예와 나쁜 예

    우리 팀의 실제 수정에서 가져왔습니다. AI에게 시킬 때 예시로 넣습니다.

    5. 검증 결과: 근거 강도와 한계

    묶음자료한계강도

    강도: 강 = 팀 피드백이 반복되고 다른 자료도 같은 방향 / 중 = 자료가 있으나 한 사이트나 영어권 실험 / 약 = 경험 요령이거나 요약만 확인 / — = 근거 없음. 모든 자료는 원문 전문이 아니라 검색 요약으로 확인했습니다.
