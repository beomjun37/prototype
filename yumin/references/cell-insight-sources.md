# 결과지 칸 확장용 심리학 자료 (2026-11-21)

규칙은 `README.md`를 따른다. **모든 항목은 [검색 요약만]이다. 논문 전문은 읽지 못했고, 초록과 요약 페이지의 내용만 확인했다.** 문구에 쓰기 전에 원문 확인이 필요하다. 결과지 본문에는 연구를 인용하지 않고, 아이디어의 출처로만 쓴다.

## 확인하지 못한 것
- Jehn (1995)의 task conflict / relationship conflict 구분: 이차 자료에서 언급만 확인했다. 기준(W/H) 칸에 쓰려면 원문 확인이 필요하다.
- Barnum effect의 정량 메타분석: 찾지 못했다. 위 검토 논문은 1985년 문헌 검토다.
