# 원문 레퍼런스 기록 (yumin/references)

문항·축 정의·해설 문구에 심리학 이론을 쓸 때, 근거를 여기에 남깁니다. 11/18 C/N 축에서 "A/T를 변형하는 과정에 오류"가 있었던 것을 계기로 만든 규칙입니다.

## 규칙

1. **원어를 그대로 적는다.** 번역어만 쓰지 않는다. 예: 신경성 = Neuroticism, 정서 안정 = Emotional Stability, 신중함 = Cautiousness(Conscientiousness의 하위 특성).
2. **링크는 1차 자료(논문, 척도 원문 사이트)를 우선한다.** 업체 블로그나 위키는 2차 자료로 표시한다.
3. **[직접 확인] / [검색 요약만] / [미확인]을 구분해 적는다.** 직접 읽은 곳만 [직접 확인]이다.
4. **우리 정의가 원문과 다르면 "변형"으로 적고 어디가 다른지 쓴다.** (축 이름을 바꾸는 순간 원문의 측정 대상이 달라질 수 있다.)
5. **문항을 만들 때는 대응하는 원문 문항을 원어 그대로 같이 적는다.** 대응이 없으면 "대응 없음"이라고 쓴다.
6. **다른 축과 겹치는지 확인한다.** (예: "신중"은 성실성 쪽이라 마감 리듬 축과 겹친다.)

## 새 개념을 가져올 때 체크리스트

- [ ] 원어 용어와 출처(저자, 연도, 링크)를 적었는가
- [ ] 원문이 재는 것과 우리 정의가 같은가, 다르다면 차이를 적었는가
- [ ] 직접 읽은 자료와 요약으로만 본 자료를 구분했는가
- [ ] 이미 있는 축(충전, 일을 보는 눈, 기준, 마감 리듬)과 겹치지 않는가
- [ ] 번역이 필요하면 공식 번역이 있는지, 한국인 표본으로 검증됐는지 확인했는가 (없으면 "번안, 미검증"으로 표시)

## 문서 작업 원칙 (11/22 김유민 님 지시)
- 표는 내용에 맞춰 열 너비를 자동 맞춤처럼 조정한다. ID나 개수처럼 내용이 짧은 열은 좁게, 긴 문장이 들어가는 열은 넓게 둔다. 열 너비를 균등하게 두지 않는다.
- 드라이브에 올리는 HTML은 스크립트 없이 정적으로 만든다(드라이브 미리보기는 스크립트를 실행하지 않는다).

## 버전 번호 (11/22 김유민 님 지시)
- 드라이브에 공유된 현재 버전을 **1.0**으로 본다. 내부 번호와 어긋나면 헷갈리므로 같은 번호를 쓴다.
- 그 전에 내부에서 쓰던 v1~v5는 **v0.1~v0.5**로 읽는다. 단, 드라이브에 올라간 내용은 이전 "v5"와 같으므로 이전 v5 = 1.0이다(0.5라는 번호는 쓰지 않는다).
- 대응: v1→0.1, v2→0.2, v3→0.3, v4→0.4, v5→1.0. 다음 수정은 1.1부터. (11/23에 그라운드룰 1.1 반영 완료. 샘플은 아직 1.0.)
