# C/N 문항 초안 (2026-11-19, 범준 님과 논의 전 초안)

**정의(권고안 "가")**: C = 내 판단과 능력을 믿고 밀고 가는 쪽(자기확신), N = 내 판단을 한 번 더 의심하고 확인하는 쪽(자기의심). 근거와 변형 내용은 `../references/cn-axis-sources.md`.

**한계 [확실]**: 아래 문항은 제가 IPIP 원문 문항을 근거로 직장 장면으로 옮긴 것이며, 문항 자체의 신뢰도와 타당도는 검증되지 않았습니다. CSES 원문은 읽지 못해서 대응 표에 넣지 않았습니다. 한국어 번안이라 원문과 뉘앙스가 다를 수 있습니다.

형식은 기존 문항과 같습니다. 장면, A(C쪽), B(N쪽). 선택지 두 번째 줄은 속말입니다.

| # | 장면 | A (C: 자기확신) | B (N: 자기의심) | 대응하는 IPIP 원문 (원어) | 겹침 주의 |
|---|---|---|---|---|---|
| C-1 | 회의에서 내 의견과 다른 의견이 더 많았다. | 내 의견을 한 번 더 설명해 본다 / 근거가 있으니까 | 내 생각이 틀렸나 다시 따져 본다 / 다들 그러면 이유가 있겠지 | "Am sure of my ground."(C1), "Am afraid that I will do the wrong thing."(N4) | 기준(W/H)과 약간 겹칠 수 있음 |
| C-2 | 처음 맡아 보는 일이 떨어졌다. | 일단 시작하고 하면서 배운다 / 하다 보면 길이 보이겠지 | 어떻게 해야 틀리지 않을지 먼저 알아본다 / 해 본 사람한테 물어보고 시작해야지 | "Know how to get things done."(C1), "Feel that I'm unable to deal with things."(N6) | 마감 리듬(D/L)과 겹칠 수 있음 |
| C-3 | 상사가 내 결과물에 "음, 알겠어요"라고만 했다. | 별말 없으면 괜찮은 거다 / 문제 있으면 말했겠지 | 뭐가 부족했나 되짚어 본다 / 표정이 안 좋았던 것 같은데 | "Have a low opinion of myself."(N3), "Am easily intimidated."(N4) | 불안(걱정)에 가까움 |
| C-4 | 실수를 지적받았다. | 그 부분만 고치고 넘어간다 / 다음엔 안 하면 되지 | 내 일하는 방식 전체를 돌아본다 / 나한테 이런 면이 있었나 | "Feel comfortable with myself."(N3, 역), "Avoid mistakes."는 사용 안 함 | 호감도: B가 겸손해 보일 수 있음 |
| C-5 | 갑자기 내가 발표를 대신하게 됐다. | 아는 만큼 말해 보자 / 질문 오면 그때 생각하지 | 준비가 부족한데 괜찮을지 계속 걱정된다 / 자료를 한 번 더 훑어본다 | "Remain calm under pressure."(N6, 역), "Panic easily."(N6) | 기존 Q12와 비슷 |
| C-6 | 팀에서 방향을 정해야 하는데 정보가 다 모이지 않았다. | 지금 아는 걸로 정하고 간다 / 틀리면 그때 고치지 | 확인할 게 남았으면 더 알아본다 / 지금 정하면 후회할 것 같아 | "Can't make up my mind."(N6) | **신중함(Cautiousness, C6)과 겹침. 마감 리듬 축과 섞일 위험 큼** |

## 선정안 (임시)

**C-1, C-2, C-4** 를 권합니다. [추측]
- 3개 모두 "내 판단/능력을 믿는가"를 직접 묻고, 걱정이나 마감 습관과 덜 섞입니다.
- C-3, C-5는 불안 쪽이라 정의 "가"와 거리가 있고, C-6은 마감 리듬과 겹칩니다. 교체 후보로 둡니다.
- 호감도 쏠림 점검 필요: C-4는 B쪽이 겸손해 보여 B 선택이 늘 수 있고, C-1은 A쪽이 고집으로 읽힐 수 있습니다. 호감도 점검표에 올려 팀원들이 직접 평가해야 합니다.
