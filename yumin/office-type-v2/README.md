# office-type v2 (1118 회의 안건 추천안 프로토)

`office-type/index.html`을 복사해서, 1118 회의 안건의 추천안 중 **로직으로 바꿀 수 있는 부분**만 반영한 시험용 페이지입니다. 원본(`office-type/`)은 건드리지 않았습니다.

## 반영한 것

| 안건 | 반영 내용 |
|---|---|
| 1. 판정 방식 | 5문항 조기 종료: 한 축에서 한 극이 3표를 먼저 얻으면 그 축의 남은 질문을 건너뜁니다. 갈린 축에 묻던 추가 질문(QX)은 쓰지 않습니다. 점수는 기존 0~5 점수로 환산해서 결과 계산, 공유 링크, 팀 기능이 그대로 동작합니다. |
| 1. 이탈 측정 | q5, q10, q15, q20 이벤트 추가 (분석 도구는 꺼져 있음) |
| 1. 선택지 호감도 균형 | 예시 1문항만 재작성 ("마감 일주일 전이다") |
| 2. 경계 처리 | 3:2로 간신히 넘은 축이 하나라도 있으면 "한쪽으로 단정하기 어려운 부분" 해설을 추가합니다. 문구는 초안입니다. |

## 반영하지 못한 것

- 안건 3, 4의 칸별 문구(전용 칸 96개 + 16유형 칸 80개): 문구 작업이라 코드로 대신할 수 없습니다.
- 선택지 호감도 균형 재작성 나머지 24문항
- 질문이 줄어든 만큼 요일·버디 연출(`WHEN`, `SAY`, `BUDDY`)이 중간에 끝납니다. 연출 데이터 조정은 하지 않았습니다.

## 시험 결과 (헤드리스 브라우저, 무작위 응답 40회)

- 질문 수 평균 20.3 (최소 17, 최대 24). 기존 방식은 평균 약 29.
- 경계 해설 노출 33/40. 무작위 응답은 경계가 많이 나오는 편이라, 실제 사용자에서의 비율은 테스트에서 확인해야 합니다.
- 뒤로 가기와 이전 선택 표시, 결과 화면과 공유 링크 생성이 동작합니다.

## 기타

- 방문 집계(GoatCounter)는 꺼 두었습니다. 검색 노출 방지(`noindex`)를 넣었습니다.
- 원본의 갈린 축 추가 질문 코드는 지우지 않고 남겨 두었습니다. 아래쪽 `<script>`가 이를 덮어씁니다.
