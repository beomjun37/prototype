# 검증 계획: 우리 축 점수와 Big Five의 수렴 타당도

**목적**: 이 테스트의 5개 축이 실제로 의도한 성향(외향성, 지성·상상, 우호성, 성실성, 정서 안정)과 관련되는지 확인합니다. 참고한 소스는 `../question-review/ipip-sources.md`입니다.

**한계를 먼저**: 이 검증은 "축 점수가 해당 성향과 함께 움직이는가"만 봅니다. 결과 유형이 "정확하다"거나 "과학적으로 검증됐다"는 근거가 되지 않으므로 서비스 문구에 그렇게 쓰지 마세요.

## 필요한 것

| 항목 | 내용 |
| --- | --- |
| 참가자 | 약 85명 이상 (r=.30을 80% 확률로, 유의수준 5%로 잡는 데 필요한 수). 30명 미만이면 분석은 가능하지만 해석하기 어렵습니다. |
| 참가자가 하는 일 | (1) 테스트를 끝까지 하고 결과 화면 주소를 복사 (2) IPIP 20문항에 1~5점으로 응답 |
| 소요 시간 | 테스트 3분 + 설문 약 2분 |
| 수집 항목 | 임의의 참가자 번호, 결과 주소, 20문항 응답. 이름, 연락처, 회사 정보는 받지 않습니다. |

결과 주소 끝의 5자리 코드(`#r=`)에는 유형과 축별 점수만 들어 있고 개인 정보는 없습니다.

## 진행 순서

1. `survey-text.md`의 안내문과 20문항으로 설문을 만듭니다(Google Forms 등). 응답 항목에 "결과 화면 주소"를 넣습니다.
2. 11/18~22 테스트 참가자 일부에게 설문 링크를 함께 보냅니다.
3. 응답을 `template.csv`의 헤더(열: id, result, 그 뒤 i번호 20개)와 같은 형식으로 내보냅니다.
4. `node yumin/validation/analyze.js 응답.csv 보고서.md`로 분석합니다.

## 분석이 내놓는 것

- 영역별 내적 일관성(Cronbach alpha)
- **수렴**: 우리 축과 대응 영역의 상관과 95% 신뢰구간
- **판별**: 우리 축 x 영역 전체 상관 행렬. 대응 영역의 상관이 다른 영역보다 커야 합니다.

## 판정 기준 (관례, 이 서비스에 맞춘 값이 아님)

| 대응 영역과의 상관(기대 부호 방향) | 판정 | 조치 |
| --- | --- | --- |
| .40 이상 | 양호 | 유지 |
| .30 ~ .40 | 보통 | 문항 점검 |
| .30 미만 | 재작성 대상 | `../question-review/question-map.md`의 "하" 문항부터 재작성 |
| 부호 반대 | 문제 | 축의 극 방향이나 문항 의미 재검토 |

## 이 검증으로 알 수 없는 것

- **문항별 구분력**: 결과 코드에는 축별 점수(0~5)만 들어 있어서, 개별 문항이 축 점수와 얼마나 맞는지는 볼 수 없습니다. 문항 단위 분석이 필요하면 문항별 선택 기록을 따로 남겨야 합니다.
- **재현성(두 번 하면 같은 유형이 나오는가)**: 같은 사람에게 2번 받아야 합니다. 일부 참가자에게 1주 뒤 재응답을 요청하면 볼 수 있습니다.

## 파일

- `mini20-ko.json`: 20문항 영어, 한국어, 영역, 방향
- `template.csv`: 응답 CSV 형식(헤더만)
- `analyze.js`: 분석 스크립트 (결과 주소에서 축 점수를 복원)
- `survey-text.md`: 설문 안내문과 문항
- `make-demo.js`, `demo-responses.csv`, `demo-report.md`: 동작 확인용 **합성 데이터**. 실제 응답이 아닙니다.
