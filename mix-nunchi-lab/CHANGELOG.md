# mix-nunchi-lab 변경 기록

원본(mix-nunchi/)은 그대로 두고, 이 폴더에서만 작은 개선을 라운드로 쌓습니다. 한 줄에 무엇을 깎거나 고쳤는지 적어요.

## 라운드 1 (10/29)
- 깎음: 소개 화면과 상사 고르기 화면을 한 화면으로 합쳤어요. 설명 문단, 3단계 안내, 캐릭터 소개 줄, 뒤로 가기, 결재란 장식을 뺐어요.
- 고침: 첫 화면 문장은 "올해 상사 눈치, 몇 점이었을까?"와 "상사가 오기 전에 화면만 숨기면 돼요. 45초." 두 줄만 남겼어요.
- 고침: 상사 설명을 장면이 떠오르는 말로 바꿨어요. 예) "아직이야?" 말이 끝나기 전에 와요.
- 고침: 유형 판정 기준값을 상사 난이도별로 따로 두고, 봇 시뮬레이션 중앙값에 맞췄어요. 전에는 어떤 상사로 해도 똑게·멍게만 나왔는데, 이제 네 유형이 모두 나와요.
- 고침: 선택된 상사 카드의 "난이도" 글자 대비를 높였어요(readcheck 통과).

## 라운드 2 (10/29)
- 고침: "동료에게 보내기"가 폰에서는 공유창(카톡 포함)을 바로 열어요. 안 되는 환경에서는 문구를 복사해요.
- 고침: 공유 문구를 "우리 상사랑 궁합 38점 “반려” 나왔다. 상사가 만든 일을 당신이 수습한 1년."처럼 웃긴 한 줄이 앞에 오게 바꿨어요.
- 고침: 결과 카드 이미지 아래쪽을 같은 한 줄 평으로 채웠어요. 전에는 "올해 우리 상사 앞에서, 나는?"이라는 빈 문구였어요.
- 깎음: 결과 화면의 유형 설명 줄 2개를 한 상자로 합치고, "재미로 보는 수치예요"와 맨 아래 안내 문장을 뺐어요.

## 라운드 3 (10/29)
- 고침: 작은 폰(375x667)에서 게임 화면이 살짝 넘쳐 스크롤되던 걸 맞췄어요. 숨기기 버튼이 항상 화면 안에 들어와요.
- 고침: 상사 신호 알림의 느낌표를 빨간 원으로 바꿔서 한눈에 "지금 숨어야 한다"가 보여요.
- 확인: 봇 160판(상사 4종 x 40판)에서 유형이 똑게 42, 똑부 46, 멍게 36, 멍부 36으로 나왔어요. 멍부 쪽이 적어서 까다로운 상사의 손속도 기준을 조금 낮췄어요.

## 라운드 4 (10/29)
- 고침: 공유 문구와 카드의 한 줄 평이 너무 짧게 잘리지 않게, 첫 문장이 12자 미만이면 다음 문장까지 이어 붙여요. 예) "세상 평화로운 팀. 마감 전날만 빼고요."
- 고침: 똑부×똑부 궁합 문구를 "둘 다 안 쉬어서 회의가 15분 만에 끝나는 사이. 팀원들만 숨이 막혀요."로 바꿨어요. 첫 문장만 읽어도 웃기게요.

## 라운드 5 (10/29) · 문장 다시 쓰기
범준 피드백: "올해 상사 눈치, 몇 점이었을까?"가 무슨 말인지 모르겠다. 원인은 명사만 이어 붙이고(상사 눈치 결산, 월급루팡 지수, 들킴·무사통과) 누가 무엇을 하는지 동사를 빼먹은 문장이었어요. 화면 문장 전체를 "누가 무엇을 하는지 보이는 완결된 문장"으로 다시 썼어요.
- 고침: 첫 화면 "올해 상사 눈치, 몇 점이었을까?" → "상사 몰래 딴짓, 안 들킬 자신 있어요?" 설명도 "엑셀 화면에서 딴짓하다가 상사가 오면 숨기세요. 45초 뒤에 나와 상사의 궁합이 나와요."로요.
- 고침: 이름 "상사 눈치 결산" → "상사 몰래 딴짓". 탭 제목, 결과 이미지, 메인 목록 모두 바꿨어요.
- 고침: 게임 중 "들킴 · 합계 -10" → "들켰어요! 10점 깎여요", "무사통과" → "안 들켰어요", 버튼 "숨기기 (업무 화면)" → "숨기기"/"다시 딴짓하기".
- 고침: 결과의 "똑부 = 계획파 + 부지런" → "똑부는 계획을 먼저 세우고 부지런히 챙기는 유형이에요.", "평균 40% 지점에서 숨었어요" → "상사 알림이 뜨자마자 숨었어요."
- 고침: "월급루팡 지수" → "딴짓 점수", "이번 판 명세서" → "이번 판 기록", "2027 한 줄 조언" → "내년에 해 볼 것", "결재 올리는 중" → "결과를 계산하고 있어요". 반쯤 끊긴 문장("질문 하나 더 하기.")은 끝맺었어요.

## 라운드 6 (10/29) · 살아남은 만큼이 궁합
범준 피드백 세 가지: 컵·스테이플러 같은 사물 별명은 의미가 약하다, 사람 그림이 더 어울린다, 게임으로 상사 궁합을 본다는 논리가 별로다. 범준이 "살아남은 만큼이 궁합" 안을 골랐어요.
- 바꿈: 상사 4명을 직접 그린 사람 캐릭터로 바꾸고, 이름을 바로 떠오르는 별명으로 지었어요. 아직이야 부장, 알아서 해 팀장, 일단 해보자 과장, 허허 차장. 나를 뜻하는 평범한 직원 캐릭터도 하나 더했어요.
- 바꿈: 궁합은 이제 "고른 상사가 올 때 얼마나 빨리 숨고 안 들켰는지, 딴짓을 얼마나 했는지"로 매겨요. 게임 점수가 그대로 궁합 점수예요.
- 깎음: 플레이 습관으로 내 유형(똑부·똑게·멍부·멍게)을 맞히던 단계, 유형 설명, 유형 x 상사 궁합표를 통째로 뺐어요.
- 바꿈: 결과 16개는 상사 4명 x 궁합 4단계예요. 각각 별명과 한 줄이 있어요. 예) 아직이야 부장 50점 미만 = "부장님 단골손님".
- 바꿈: 결과 화면과 이미지 카드 맨 위에 내 별명과 "아직이야 부장 밑에서 45초 동안 4번 피하고 2번 들켰어요." 같은 사연이 와요.
- 확인: 봇 160판에서 네 구간이 40/43/38/39로 고르게 나와요. 까다로운 과장님은 점수가 낮게, 순한 차장님은 높게 나오는 쪽으로 기울어요.

## 라운드 7 (10/29) · 게임 다음에 진짜 궁합 테스트
범준 피드백: 게임 점수는 진짜 궁합이 아니고, 게임만으로는 차별점이 약하다. 범준이 "게임 다음 질문 테스트" 구조를 골랐어요.
- 바꿈: 게임 점수 이름을 "궁합"에서 "생존 점수"로 바꿨어요. 도장도 무사 퇴근, 아슬아슬, 경고, 적발로 바꿨어요. 게임 결과의 16개 별명은 그대로예요.
- 더함: 게임 결과 바로 아래에 "그럼 진짜 우리 상사와 궁합은 몇 점일까요?" 상자와 "진짜 궁합 보기" 버튼을 넣었어요.
- 더함: 질문 8개(나에 대해 4개, 상사에 대해 4개), 한 화면에 질문 하나, 누르면 바로 다음으로 넘어가요.
- 더함: 진짜 궁합 결과 화면. 내 유형 4개(먼저 끝내는 사람, 똑똑하게 아끼는 사람, 일단 뛰는 사람, 마감에 강한 사람) x 상사 4명 = 16개 궁합이에요. 게임에서 고른 상사와 질문으로 나온 상사가 다르면 그것도 알려 줘요.
- 옮김: 990원 가짜 문은 게임 결과에서 빼고 진짜 궁합 결과로 옮겼어요. 돈을 낼 이유는 "용하다"는 느낌이 있는 쪽이라서요.
- 고침: 첫 화면 설명을 "게임이 끝나면 질문 8개로 진짜 상사 궁합도 볼 수 있어요."로 바꿨어요.
- 고침: 다크 모드에서 상사 카드의 "난이도" 글자와 빨간 버튼 글자 대비가 낮던 걸 고쳤어요(readcheck 라이트·다크 통과).
- 더함: 첫 화면 맨 아래에 버전 표시(lab v7.1)를 넣었어요. 폰에서 예전 화면이 캐시로 남아 있는지 바로 확인할 수 있어요.
- 고침: 결과 이미지 팝업의 img에 빈 src가 없게 투명 1px 이미지를 기본값으로 넣었어요(디자인 점검 경고 정리).
